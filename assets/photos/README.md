CC BY 2.0 lets us use and change the photo, also in a book that is sold, if we credit the photographer, link the license, and say what we changed. The book's credits line does this. Keep it whenever the photo is used.

The Unsplash License lets us use and change the photo, also in a book that is sold, without asking. Credit is not required, but we give it anyway.

CC BY-SA 4.0 lets us use and change the photo, also in a book that is sold, if we credit the photographer, link the license, and say what we changed. Our changed version (the toned cover art) must be shared under CC BY-SA 4.0 too; the rest of the book is not affected. The book's credits line says all of this.

CC0 is public domain: no conditions. The full list of covers, captions, and which photo each book uses is `PHOTO_COVERS` in `tools/course_themes.py`. Every MCFA photo still needs the ministry's written permission before a book is printed or sold.
