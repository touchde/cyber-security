# Sources

Main references for How Computers Work. These are durable, authoritative sources; prefer teaching concepts that do not change with the latest hardware. Re-check before publishing.

## Core computing concepts

- *Operating Systems: Three Easy Pieces* (OSTEP), free online — processes, memory, files. https://pages.cs.wisc.edu/~remzi/OSTEP/
- Charles Petzold, *Code: The Hidden Language of Computer Hardware and Software* — bits, encoding, how the machine works (book).
- *Computer Systems: A Programmer's Perspective* (CS:APP) — data representation, machine code, memory (book).
- Ben Eater, breadboard computer and networking videos — how a CPU and memory really work. https://eater.net

## Numbers, text, and encoding

- The Unicode Standard — code points, UTF-8, scripts including Khmer. https://www.unicode.org
- RFC 4648, Base16/Base32/Base64 encodings. https://www.rfc-editor.org/rfc/rfc4648
- RFC 3986, URI syntax and percent-encoding. https://www.rfc-editor.org/rfc/rfc3986

## Operating systems, processes, and files

- The Linux man pages (sections 1, 2, 5) — commands, system calls, file formats. https://man7.org/linux/man-pages/
- Linux kernel documentation. https://docs.kernel.org

## Programs, executables, and boot

- Tool Interface Standard, the ELF format. (Executable formats; referenced in lessons 8 and the Reverse Engineering course.)
- UEFI Specification (firmware and boot) — https://uefi.org/specifications
- LLVM / Clang documentation — compiling the C examples. https://clang.llvm.org

## Virtualization

- Vendor documentation for VirtualBox, VMware, and Docker (concepts only; the hands-on lab is course 08).
