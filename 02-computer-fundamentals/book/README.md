# The Full Book

The full book puts all 12 sections of How Computers Work in one PDF, in English and (after translation) Khmer: a cover, a contents page, "How to Use This Book", the 12 sections (each with a divider page), and "References" at the end.

Build it from the repo root (Google Chrome required):

    python3 tools/build_lessons.py computer-fundamentals --book

PDFs are written to `output/02-computer-fundamentals/how-computers-work/`.
