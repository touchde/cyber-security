## References

Durable, authoritative sources used to write this book. Re-check before relying on a specific detail, and record the exact tools and versions behind any command output.

### Core computing

- *Operating Systems: Three Easy Pieces* (OSTEP), free online — https://pages.cs.wisc.edu/~remzi/OSTEP/
- Charles Petzold, *Code: The Hidden Language of Computer Hardware and Software* (book)
- *Computer Systems: A Programmer's Perspective* (book)
- Ben Eater, breadboard computer videos — https://eater.net

### Numbers, text, encoding

- The Unicode Standard — https://www.unicode.org
- RFC 4648 (Base64) — https://www.rfc-editor.org/rfc/rfc4648
- RFC 3986 (URIs, percent-encoding) — https://www.rfc-editor.org/rfc/rfc3986

### OS, programs, boot

- The Linux man pages — https://man7.org/linux/man-pages/
- LLVM / Clang documentation — https://clang.llvm.org
- UEFI Specification — https://uefi.org/specifications

*The tools used for the command output in this book (`xxd`, `base64`, `file`, `ps`, `uptime`, `clang`) were run on a macOS machine; output differs by system and version.*
