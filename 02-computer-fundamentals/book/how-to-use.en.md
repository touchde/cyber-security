## How to Use This Book

This is the second course in a cyber security program. It assumes only the first course, Security Fundamentals; no programming and no prior knowledge of how computers work inside. It has 12 sections, each building on the ones before, so read them in order.

Every section follows the same plan: **What You Will Learn** and **Before You Start**; numbered **topics**, one idea each; **Common Mistakes**; and **Summary**, **Check Your Understanding**, and **Practice** with answers and worked examples.

**This course has a little code and commands.** Later sections show small C programs and short shell commands (`xxd`, `file`, `ps`, `uptime`) to let you *see* memory, files, and processes for real. Everything is explained from zero and runs on your own computer. You need no programming to read it; to try the commands, a terminal helps.

**Run things on your own machine only.** The one rule from Security Fundamentals applies throughout: only look at systems you own or have written permission to test. Every example here is for understanding and defending; nothing targets a system that isn't yours. Keys, prices, and names in examples are made up.

**The through-line.** This course is the trunk the later courses grow from: the stack and buffers lead to Binary Exploitation; executables to Reverse Engineering and Malware Analysis; volatile memory and deleted files to Digital Forensics; processes and the kernel to everything. Each idea is introduced lightly here and names the course that goes deep.
