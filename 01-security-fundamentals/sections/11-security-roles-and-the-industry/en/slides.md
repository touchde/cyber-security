# The shape of the industry

Security isn't one job, it's a whole industry of specialties, like "medicine".

- **Offensive (red):** find weaknesses by attacking, with permission.
- **Defensive (blue):** watch for, detect, and respond to attacks.
- **Engineering / architecture:** build systems secure by design.
- **GRC:** manage security as a business, policy, risk, audits.

**You don't have to be a brilliant hacker.** Many top roles are defensive, engineering, or GRC. Demand far exceeds supply, including locally and remotely.

---

<!-- 1.3 -->

# Offensive and defensive roles

**Offensive (ethical hackers), with permission:**

- **Pentester:** test a scoped system, report the fixes.
- **Red teamer:** broad, stealthy, goal-based engagements.
- **Bug bounty hunter:** independent, via published programs.

**Defensive (blue, the larger side, where many start):**

- **SOC analyst:** watch alerts and logs, a common entry job.
- **Incident responder:** contain and recover from incidents.
- **Forensics / threat intel / threat hunter.**

Both are more methodical testing and **report writing** than dramatic hacking.

---

<!-- 1.4 -->

# Engineering and GRC roles

**Engineering / architecture, build security in:**

- **Security engineer:** build and run defenses, automate.
- **AppSec / cloud engineer:** secure software and cloud.
- **Security architect:** design how it all fits together.

**GRC, security as a business function (not technical):**

- **GRC analyst, auditor, compliance manager, CISO.**
- Rewards organization, communication, and process.

Both families are among the most in-demand and best-paid.

# How the roles work together

Not rival camps, one system of defense.

- **Red + blue = purple.** A **purple team** is a way of working: red shows blue exactly how an attack works, so blue can detect and block it. Both sides improve the defenses together.
- **Engineers build** what blue monitors and red tests. A pentest finding becomes an engineer's fix and a SOC detection.
- **GRC sets the priorities** by risk, and reports to leadership.

Understanding every role makes you better at your own.

# Certifications at a glance

A common (imperfect) way to signal knowledge. You need none to start.

| Level | Examples | For |
|---|---|---|
| Entry | CompTIA Security+ | Broad fundamentals; many first jobs |
| Offensive | OSCP, CEH | Pentest / red team |
| Defensive | SOC / blue-team certs | Operations, IR, forensics |
| Management/GRC | CISSP, CISM | Senior, architecture, governance |
| Cloud | Cloud-provider certs | Cloud security |

# Certs vs. skills: the honest truth

- **Certifications help you get interviews.**
- **Skills and a portfolio get you hired**, and keep you employed.

Hands-on practice, labs, CTFs, real projects, matters more than collecting letters.

Don't feel you must chase certs to belong: many excellent practitioners have few, and build their reputation on **demonstrated work**.

That demonstrated work is what the rest of this program builds.
