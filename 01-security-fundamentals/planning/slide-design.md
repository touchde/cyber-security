# Security Fundamentals — Slide and Book Design

Follows the shared [style guide](../../STYLE-GUIDE.md), except that each course has its own look. The theme is "blueprint": the calm, clear look of an architect's plan, because this course lays the foundation the whole program is built on.

| | Security Fundamentals |
|---|---|
| Title slides | Deep navy blueprint background, thin amber grid lines, the course mark, and the title in white |
| Headings and accents | Amber on navy; navy on light slides |
| Body slides | Light background (off-white), navy headings, dark text |
| Tables | Navy header row, light rows, amber rule under the header |
| Callouts | The shared Note, Tip, Warning, and Practice callouts; Warning keeps its own red |
| Recap slides | Pale amber, with a navy top edge |
| Fonts | Inter (text) and JetBrains Mono (the little code there is), both open-licensed |
| Khmer font | Google Sans |
| Book cover | Navy blueprint grid, the course mark, title in white, author and date |

Corners stay square. The few code or command examples use a plain dark code panel with a light output box under it, as in the style guide.

## Logo

- No brand logo. The **course mark** is a navy tile with a white "foundation/layers" icon from Material Symbols (Apache License 2.0), suggesting the base layer everything stacks on. Made by the shared `assets/build_course_icons.py` once the assets are set up.
- Framework names (NIST, CIS, ISO, OWASP, MITRE ATT&CK) are used only to refer to their public work; their logos are not used.
