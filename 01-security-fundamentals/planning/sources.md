# Sources

Main references for Security Fundamentals. Fundamentals are well-settled, so we follow mainstream, authoritative sources and cite them with dates. Re-check before publishing, because frameworks and figures change.

## Frameworks and Standards

- NIST Cybersecurity Framework 2.0 (2024): https://www.nist.gov/cyberframework
- NIST SP 800-30, Guide for Conducting Risk Assessments: https://csrc.nist.gov/pubs/sp/800/30/r1/final
- NIST SP 800-63 Digital Identity Guidelines (passwords, MFA): https://pages.nist.gov/800-63-3/
- CIS Critical Security Controls v8.1: https://www.cisecurity.org/controls
- ISO/IEC 27001 and 27002 (information security management): https://www.iso.org/standard/27001
- MITRE ATT&CK: https://attack.mitre.org

## Attacks, Risks, and Guidance

- OWASP (Open Worldwide Application Security Project): https://owasp.org
- OWASP Top 10 (web): https://owasp.org/www-project-top-ten/
- Verizon Data Breach Investigations Report (DBIR), for how attacks start: https://www.verizon.com/business/resources/reports/dbir/
- CISA (US Cybersecurity and Infrastructure Security Agency) guidance: https://www.cisa.gov
- Have I Been Pwned (breach exposure), for the password lesson: https://haveibeenpwned.com

## Law and Ethics (Cambodia and general)

- Cambodia's draft/related cybercrime and data frameworks — confirm the current law and cite it before publishing the ethics lesson. Do not state legal specifics without a current source.
- (US) Computer Fraud and Abuse Act, as a well-documented example of computer-crime law: https://www.justice.gov/criminal/ccips
- EU GDPR, as the widely-used data-protection reference: https://gdpr.eu

## Careers and Roles

- NIST NICE Workforce Framework for Cybersecurity: https://niccs.cisa.gov/workforce-development/nice-framework
