# Security Fundamentals

The core ideas every security person uses: the CIA triad, threats and risk, common attacks, controls, ethics and the law, and the main frameworks.

**Path:** Foundations
**Before this course:** None. This is the first course.

**Status:** planning done; **all 12 lessons written in English** (topic-first), and **built to PDF**, lesson books, slide decks, and the 104-page full book, in [`output/01-security-fundamentals/`](../output/01-security-fundamentals/). Next: your review, then optional diagrams and the Khmer versions. See the [task breakdown](planning/tasks.md).

Build any time (needs Google Chrome):

```sh
python3 tools/build_lessons.py security-fundamentals            # all 12 lessons
python3 tools/build_lessons.py security-fundamentals --book     # the full book
```
