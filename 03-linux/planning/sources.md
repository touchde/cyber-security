# Sources

Main references for Linux for Security. Prefer durable, authoritative sources; command behavior is stable, but check tool versions. Record the exact distribution and versions behind any command output.

## Linux and the command line

- The Linux man pages (sections 1, 5, 8) — the authoritative reference for every command. https://man7.org/linux/man-pages/
- The Ubuntu Server Guide — https://ubuntu.com/server/docs
- The Bash Reference Manual — https://www.gnu.org/software/bash/manual/
- *The Linux Command Line* by William Shotts (free online) — https://linuxcommand.org/tlcl.php

## Security and hardening

- CIS Benchmarks for Ubuntu Linux (hardening baselines) — https://www.cisecurity.org/benchmark/ubuntu_linux
- Ubuntu Security documentation — https://ubuntu.com/security
- OpenSSH manual and hardening guidance — https://www.openssh.com/manual.html
- `ufw` (Uncomplicated Firewall) documentation — https://help.ubuntu.com/community/UFW
- fail2ban documentation — https://github.com/fail2ban/fail2ban

## Distributions and tools

- Ubuntu — https://ubuntu.com
- Kali Linux (the attacker distribution used in later courses) — https://www.kali.org
- VirtualBox — https://www.virtualbox.org ; UTM (Apple Silicon) — https://mac.getutm.app
