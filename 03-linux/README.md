# Linux for Security

Working on the Linux command line: files, users, permissions, processes, logs, SSH, and hardening a server.

**Path:** Foundations
**Before this course:** How Computers Work.

**Status:** planning done; writing the 13 lessons. See the [task breakdown](planning/tasks.md).
